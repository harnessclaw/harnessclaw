# Security policy

## Report a vulnerability

Please report suspected security vulnerabilities through GitHub's
[private vulnerability reporting form](https://github.com/harnessclaw/harnessclaw/security/advisories/new).
You need a GitHub account to submit a report. The report is shared privately with
the repository's security maintainers.

Include the affected version or commit, operating system, reproduction steps or
a minimal proof of concept, and the potential impact. Remove API keys, tokens,
personal data, and other secrets from attachments and logs.

Please use the private report thread to discuss investigation, fixes, and
coordinated disclosure. Avoid posting unpatched vulnerability details in public
issues or pull requests. Ordinary bugs and feature requests belong in
[GitHub Issues](https://github.com/harnessclaw/harnessclaw/issues).

## Security updates

Check the [releases](https://github.com/harnessclaw/harnessclaw/releases) and
[published security advisories](https://github.com/harnessclaw/harnessclaw/security/advisories)
for available updates and affected versions.
